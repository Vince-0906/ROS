# 电机
![12V 370 减速电机尺寸图](../../_resources/9.2%20硬件/9cffdf80bf93105f8f224a1740b2f22d_MD5.jpg)
## 参数
12V，370减速电机，额定转速130rpm，额定电流0.5A，转矩0.058nm
，其中L为减速器，主要功能为降低转速，增加转矩
# 单片机
ESP32
## 进入虚拟环境并激活
```bash
cd /home/szc/.platformio/penv
. bin/activate
```
## 初始化
```bash
pio project init
```
## ini配置
```ini
[env:szcbot]
platform = espressif32
board = esp32dev
framework = arduino
```
## 编译
```bash
pio run
```
## 上传
```bash
pio run -t upload
```
