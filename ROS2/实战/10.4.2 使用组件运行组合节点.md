# 查看当前环境可使用组件
```bash
ros2 component types
```
# 运行test
```bash
ros2 run rclcpp_components component_container --ros-args -r __node:=compent_test
```
# 查看component
```bash
ros2 component list
```
# 加载组件
```bash
ros2 component load /compent_test composition composition::Talker
```
# 指定节点名和命名空间
```bash
ros2 component load /compent_test composition composition::Talker --node-name szc --node-namespace /ns
```
# 卸载
```bash
ros2 component unload /compent_test 1 2
```
