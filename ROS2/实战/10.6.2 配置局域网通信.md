# 修改域ID
```bash
export ROS_DOMAIN_ID=1
ros2 run demo_nodes_cpp talker
```
如果直接打开新终端输入
```bash
ros2 topic list
```
则会返回
```bash
/parameter_events
/rosout
```
如果指定域ID
```bash
export ROS_DOMAIN_ID=1
ros2 topic list
```
则会返回
```bash
/chatter
/parameter_events
/rosout
```
# 限制本机通信
```bash
export ROS_LOCALHOST_ONLY=1
```
