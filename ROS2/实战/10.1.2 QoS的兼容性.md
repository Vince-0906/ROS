# 可靠性 QoS 策略的兼容性

|**发布者**|**订阅者**|**兼容性**|
|---|---|---|
|Best effort (尽力而为)|Best effort (尽力而为)|是|
|Best effort (尽力而为)|Reliable (可靠性)|否|
|Reliable (可靠性)|Best effort (尽力而为)|是|
|Reliable (可靠性)|Reliable (可靠性)|是|

# 持久性 QoS 策略的兼容性

| **发布者**                | **订阅者**                | **兼容性** | **结果**     |
| ---------------------- | ---------------------- | ------- | ---------- |
| Volatile (易失性)         | Volatile (易失性)         | 是       | 仅适用于新消息    |
| Volatile (易失性)         | Transient local (瞬态本地) | 否       | 无通信        |
| Transient local (瞬态本地) | Volatile (易失性)         | 是       | 仅适用于新消息    |
| Transient local (瞬态本地) | Transient local (瞬态本地) | 是       | 适用于新消息和旧消息 |

# 活跃度 QoS 策略的兼容性

| **发布者**                 | **订阅者**                 | **兼容性** |
| ----------------------- | ----------------------- | ------- |
| Automatic (自动)          | Automatic (自动)          | 是       |
| Automatic (自动)          | Manual by topic (按主题手动) | 否       |
| Manual by topic (按主题手动) | Automatic (自动)          | 是       |
| Manual by topic (按主题手动) | Manual by topic (按主题手动) | 是       |
