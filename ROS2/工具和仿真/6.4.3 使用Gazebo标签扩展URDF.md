# gazebo标签
```xacro
    <gazebo reference ="${wheel_name}_link">
        <material>Gazebo/Yellow</material>
        <mu1 value="20.0"/>
        <mu2 value="20.0"/>
        <kp value="1000000000.0"/>
        <kd value="1.0"/>
    </gazebo>
```
# 各个变量含义
`mu1`表示切向摩擦系数
`mu2`表示法向摩擦系数
`kp`表示接触的刚度系数
`kd`表示阻尼系数
`<material>Gazebo/Yellow</material>`表示颜色
默认的`mu1`，`mu2`为1.0；`kp`默认为10000000000.0；`kd`默认为1.0
