# gazebo_control_plugin.xacro
```xacro
<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro">
    <xacro:macro name="gazebo_control_plugin">
        <gazebo>
            <!-- 差速驱动插件：控制两轮差速机器人的运动 -->
            <plugin name='gz::sim::systems::DiffDrive' filename='gz-sim-diff-drive-system'>
                <!-- 左右轮子关节名称 -->
                <left_joint>left_wheel_joint</left_joint>
                <right_joint>right_wheel_joint</right_joint>

                <!-- 运动学参数 -->
                <wheel_separation>0.2</wheel_separation>  <!-- 轮子间距（米） -->
                <wheel_radius>0.0325</wheel_radius>        <!-- 轮子半径（米） -->

                <!-- 坐标系配置 -->
                <frame_id>odom</frame_id>                  <!-- 里程计坐标系 -->
                <child_frame_id>base_footprint</child_frame_id>  <!-- 机器人基座坐标系 -->

                <!-- 话题名称配置 -->
                <topic>/cmd_vel</topic>                    <!-- 速度控制话题 -->
                <odom_topic>/odometry</odom_topic>         <!-- 里程计发布话题 -->
                <tf_topic>/tf</tf_topic>                   <!-- TF变换话题 -->
            </plugin>

            <!-- 关节状态发布插件：发布轮子关节的状态信息 -->
            <plugin name='gz::sim::systems::JointStatePublisher' filename='gz-sim-joint-state-publisher-system'>
                <topic>/joint_states</topic>               <!-- 关节状态发布话题 -->
                <joint_name>left_wheel_joint</joint_name>  <!-- 左轮关节 -->
                <joint_name>right_wheel_joint</joint_name> <!-- 右轮关节 -->
            </plugin>
        </gazebo>
   </xacro:macro>
</robot>

```

## 操作方法
### 键盘九宫格布局预览

| **u (左前)**   | **i (前进)**   | **o (右前)**   |
| ------------ | ------------ | ------------ |
| **`j` (左转)** | **`k` (停止)** | **`l` (右转)** |
| **`m` (左后)** | **`,` (后退)** | **`.` (右后)** |
### 1. 移动控制键

| **按键** | **功能** |
| ------ | ------ |
| `i`    | 前进     |
| `,`    | 后退     |
| `j`    | 左转     |
| `l`    | 右转     |
| `u`    | 左前方移动  |
| `o`    | 右前方移动  |
| `m`    | 左后方移动  |
| `.`    | 右后方移动  |
| `k`    | 停止     |
### 2. 速度调节键

| **按键** | **功能**      |
| ------ | ----------- |
| `q`    | 同时增加线速度和角速度 |
| `z`    | 同时减少线速度和角速度 |
| `w`    | 只增加线速度      |
| `x`    | 只减少线速度      |
| `e`    | 只增加角速度      |
| `c`    | 只减少角速度      |
# bridge.yaml配置
因为使用的是Jazzy版本，所以需要桥接
```yaml
# ROS 2 与 Gazebo 之间的话题桥接配置

# 时钟同步：从 Gazebo 到 ROS 2，用于仿真时间同步
- ros_topic_name: "clock"
  gz_topic_name: "/clock"
  ros_type_name: "rosgraph_msgs/msg/Clock"
  gz_type_name: "gz.msgs.Clock"
  direction: "GZ_TO_ROS"

# 速度控制话题：从 ROS 2 到 Gazebo，用于控制机器人运动
- gz_topic_name: "/cmd_vel"
  ros_type_name: "geometry_msgs/msg/Twist"
  gz_type_name: "gz.msgs.Twist"

# 激光雷达扫描数据：从 Gazebo 到 ROS 2（当前机器人未配置激光雷达）
- ros_topic_name: "scan"
  gz_topic_name: "/lidar"
  ros_type_name: "sensor_msgs/msg/LaserScan"
  gz_type_name: "gz.msgs.LaserScan"
  direction: "GZ_TO_ROS"

# 激光雷达点云数据：从 Gazebo 到 ROS 2（当前机器人未配置激光雷达）
- ros_topic_name: "points"
  gz_topic_name: "/lidar/points"
  ros_type_name: "sensor_msgs/msg/PointCloud2"
  gz_type_name: "gz.msgs.PointCloudPacked"
  direction: "GZ_TO_ROS"

# 里程计话题：从 Gazebo 到 ROS 2，提供机器人位置和速度信息
- ros_topic_name: "odometry"
  gz_topic_name: "/odometry"
  ros_type_name: "nav_msgs/msg/Odometry"
  gz_type_name: "gz.msgs.Odometry"
  direction: "GZ_TO_ROS"

# 关节状态话题：从 Gazebo 到 ROS 2，提供轮子关节的位置和速度信息
- ros_topic_name: "joint_states"
  gz_topic_name: "/world/room/model/szcbot/joint_state"
  ros_type_name: "sensor_msgs/msg/JointState"
  gz_type_name: "gz.msgs.Model"
  direction: "GZ_TO_ROS"

# TF变换话题：从 Gazebo 到 ROS 2，提供坐标系之间的变换关系
- ros_topic_name: "tf"
  gz_topic_name: "/tf"
  ros_type_name: "tf2_msgs/msg/TFMessage"
  gz_type_name: "gz.msgs.Pose_V"
  direction: "GZ_TO_ROS"

# IMU传感器数据：从 Gazebo 到 ROS 2（当前机器人未配置IMU）
- ros_topic_name: "imu"
  gz_topic_name: "/imu"
  ros_type_name: "sensor_msgs/msg/Imu"
  gz_type_name: "gz.msgs.IMU"
  direction: "GZ_TO_ROS"

# 相机图像数据：从 Gazebo 到 ROS 2（当前机器人未配置相机）
- gz_topic_name: "/camera"
  ros_type_name: "sensor_msgs/msg/Image"
  gz_type_name: "gz.msgs.Image"
  direction: "GZ_TO_ROS"

# 相机参数信息：从 Gazebo 到 ROS 2（当前机器人未配置相机）
- gz_topic_name: "/camera_info"
  ros_type_name: "sensor_msgs/msg/CameraInfo"
  gz_type_name: "gz.msgs.CameraInfo"
  direction: "GZ_TO_ROS"
```
