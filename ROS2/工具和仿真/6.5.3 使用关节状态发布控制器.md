# 查看controllers命令
```bash
ros2 control list_controllers
```
# szcbot_ros2_controller.yaml配置新增
```yaml
    szcbot_joint_state_broadcaster:
      type: joint_state_broadcaster/JointStateBroadcaster
```
# launch新增
```python
            action_load_joint_state_controller = launch.actions.ExecuteProcess(
        cmd='ros2 control load_controller szcbot_joint_state_broadcaster --set-state active'.split(' '),
        output='screen'
    )
    
    return launch.LaunchDescription([
        launch.actions.RegisterEventHandler(
            event_handler=launch.event_handlers.OnProcessExit(
                target_action=action_create,
                on_exit=[action_load_joint_state_controller],
            )
        )
    ])
```
# 关闭controllers
```bash
ros2 control set_controller_state szcbot_joint_state_broadcaster inactive
```
# 卸载controllers
```bash
ros2 control unload_controller szcbot_joint_state_broadcaster
```
