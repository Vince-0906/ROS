# 开始记录
```bash
ros2 bag record /turtle1/cmd_vel
```
`/turtle1/cmd_vel`为话题名称
使用空格暂停
# 播放
```bash
ros2 bag play rosbag2_2026_08_02-23_08_00/
```
`rosbag2_2026_08_02-23_08_00/`为文件夹名
使用空格暂停/恢复
使用右方向键播放下一条消息
使用上方向键增加速率10%
使用下方向键减少速率10%
