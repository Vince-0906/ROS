# 智能指针（共享指针）
> [!info]+
> 不会进行内存拷贝，效率提高；使用完后自动回收，不会造成内存泄露
## 代码
```c++
    auto p1 = std::make_shared<std::string>("this is a str");//std::make_shared<数据类型/对象类型>(参数)；返回值，对应类的共享指针   std::make_shared<std::string> 写为auto
    std::cout << "p1的引用计数:" << p1.use_count() << ",指向的内存地址:" << p1.get() << std::endl;//1
    
    auto p2 = p1; //p2和p1指向同一块内存
    std::cout << "p1的引用计数:" << p1.use_count() << ",指向的内存地址:" << p1.get() << std::endl;//2
    std::cout << "p2的引用计数:" << p2.use_count() << ",指向的内存地址:" << p2.get() << std::endl;//2

    p1.reset(); //释放p1指向的内存，引用计数减1,不指向"this is a str"所在内存
    std::cout << "p1的引用计数:" << p1.use_count() << ",指向的内存地址:" << p1.get() << std::endl;//0
    std::cout << "p2的引用计数:" << p2.use_count() << ",指向的内存地址:" << p2.get() << std::endl;//2-1=1

    std::cout << "p2指向的内存数据:" << p2->c_str() << std::endl;//调用成员方法c_str()，返回指向字符串的指针
```
## 输出
```bash
p1的引用计数:1,指向的内存地址:0x579bd82ad2c0
p1的引用计数:2,指向的内存地址:0x579bd82ad2c0
p2的引用计数:2,指向的内存地址:0x579bd82ad2c0
p1的引用计数:0,指向的内存地址:0
p2的引用计数:1,指向的内存地址:0x579bd82ad2c0
p2指向的内存数据:this is a str
```

# Lambda表达式（匿名函数）
## 通用表达
```c++
[capture list](parameters) -> return_type {function body}
[捕获列表](函数参数列表) -> 返回值 {函数体}
[&(表示作用域全部捕获)]
```
## 代码
```c++
    auto add =[](int a,int b)->int{return a+b;}; //lambda表达式，返回值类型为int
    int sum = add(200,50);
    auto print_sum =[sum]()->void
    {
        std::cout << "sum=" << sum << std::endl;
    };
    
    print_sum();
```
## 输出
```bash
sum=250
```

# 函数包装器

```c++
#include <iostream>
#include <functional>

void save_with_free_function(const std::string& file_name)
{
    std::cout<<"自由函数:"<<file_name<<std::endl;
}

class File_Save
{
    private:
    /*data*/
    public:
    File_Save(/* args */)=default;
    ~File_Save()=default;
    void save_with_member_function(const std::string& file_name)
    {
        std::cout<<"成员函数:"<<file_name<<std::endl;
    }
};

int main()
{
    File_Save file_save;

    //Lambda函数

    auto save_with_lambda_fun = [](const std::string& file_name)->void
    {
        std::cout<<"lambda函数:"<<file_name<<std::endl;
    };

    /*
    save_with_free_function("file.txt");
    file_save.save_with_member_function("file.txt");
    save_with_lambda_fun("file.txt");
    */
   
   
    std::function<void(const std::string&)> save_1=save_with_free_function;
   std::function<void(const std::string&)> save_2=save_with_lambda_fun;
   //成员函数，放入包装器
   std::function<void(const std::string&)> save_3=std::bind(&File_Save::save_with_member_function,&file_save,std::placeholders::_1);
   
   //统一的调用方法
   save_1("file.txt");
   save_2("file.txt");
   save_3("file.txt");

   return 0;
}
```
# 各种函数的区别和使用场景
## 区别
### 成员函数-Member Function
- **是什么**：写在 `class`（类）**内部**的函数。它属于某个具体的“对象”。
- **形象比喻**：**对象的“专属技能”**。比如“狗”有“汪汪叫”的技能，“汽车”有“踩刹车”的技能。
```cpp
class Dog {
public:
    void bark() {  // 成员函数：属于 Dog 这个类
        std::cout << "汪汪！\n";
    }
};

Dog my_dog;
my_dog.bark();  // 必须通过具体的对象（my_dog）来调用
```
### 自由函数-Free Function
- **是什么**：不属于任何 `class` 的**独立函数**（有时也叫全局函数或普通函数）。
- **形象比喻**：**公共工具箱里的“通用工具”**。比如一把公用的尺子，谁都可以拿来用，不需要绑定在某只特定的“狗”或“汽车”身上。
```cpp
int add(int a, int b) {
    return a + b;
}

int sum = add(3, 5);  // 直接调用，不需要创建对象
```
### Lambda函数-Lambda Function
- **是什么**：**没有名字、临时写在当场的“一次性小函数”**（也叫匿名函数）。在 C++11 之后引入。
- **形象比喻**：**写在便签纸上的“临时指令”**。用完就可以扔掉，懒得专门为了它在别处正式写一个 `add` 或 `bark` 函数。
**基础语法格式**：`[](参数) {函数体 }`
```cpp
// 1. 简单定义并直接赋给变量
auto print_hello = []() {
    std::cout << "Hello!\n";
};
print_hello();  // 调用它

// 2. 最常用的场景：直接作为参数传给别的工具
std::vector<int> nums = {3, 1, 4, 2};

// 告诉 std::sort：用我临时写的逻辑（从大到小）来排序
std::sort(nums.begin(), nums.end(), [](int a, int b) {
    return a > b;  // 一次性的排序规则
});
```
## 使用场景
| **函数类型**      | **一句话选择指南**                | **典型使用场景**                                          |
| ------------- | -------------------------- | --------------------------------------------------- |
| **成员函数**      | 逻辑**必须操作某个对象的内部数据**时       | 比如 `robot.move()`（控制机器人移动）、`user.getName()`（获取用户名字） |
| **自由函数**      | 逻辑是**纯粹的工具**，不依赖具体对象时      | 比如 `std::max(a, b)`（求最大值）、`math::sqrt(x)`（开平方）      |
| **Lambda 函数** | 逻辑**非常短小**，且**只在当前位置用一次**时 | 比如给 `std::sort` 自定义排序规则、临时过滤列表中的数据                  |
一句话就是
- 搞清楚“是谁的能力” -> 用**成员函数**；
- 只是“通用计算工具” -> 用**自由函数**；
- 随用随写“懒得起名字” -> 用 **Lambda 函数**。
