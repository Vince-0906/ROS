更新软件包
```bash
sudo apt update
```

安装ROS2
```bash
wget http://fishros.com/install -O fishros && bash fishros
```

创建文件夹
```bash
mkdir <name>
```

创建文件
```bash
touch 123.txt
```

编辑文件
```bash
nano 123.txt
```

查看文件
```bash
cat 123.txt
```

帮助
```bash
--help
```

删除
```bash
rm 123.txt
```
加权限
```bash
chmod a+x
```
