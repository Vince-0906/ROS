# 启动记录
```bash
ros2 launch slam_toolbox online_async_launch.py use_sim_time:=True
```
# 保存room
```bash
ros2 run nav2_map_server map_saver_cli -f room 
```
# room.yaml文件
```yaml
image: room.pgm
//关联的栅格地图图片路径
mode: trinary
//`trinary`（三值模式，默认）：将地图划分为占用、空闲和未知三种状态。  
其他可选模式包括 `scale`（按像素灰度映射为连续概率 0~100%）和 `raw`（直接使用原始像素值）。
resolution: 0.050
//地图的分辨率，单位为米/像素
origin: [-7.961, -7.977, 0]
//地图图像左下角像素点 (0,0)在世界坐标系（`map` 坐标系）中的三维位姿[X, Y, Yaw]。（坐标原点）
negate: 0
//像素颜色与占用状态的翻转标志(地图翻转)
occupied_thresh: 0.65
//判定为“占用/障碍物”的概率阈值
free_thresh: 0.196
//判定为“空闲/可通行”的概率阈值
```
